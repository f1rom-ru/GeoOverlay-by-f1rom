# GeoOverlay

Небольшое Windows-приложение на Python: по нажатию **F6** делает скриншот экрана, определяет по нему примерное место на Земле нейросетью [GeoCLIP](https://github.com/VicenteVivan/geo-clip) и показывает координаты в левом верхнем углу экрана. Координаты самого вероятного места копируются в буфер обмена.

> ⚠️ Учебный проект. Модель определяет страну или регион, а не точку на карте. Не используйте программу в рейтинговых и соревновательных играх (в том числе GeoGuessr): это считается читерством и может привести к бану.

## Возможности

- Глобальная горячая клавиша **F6** работает, даже когда окно программы не в фокусе.
- Оверлей поверх экрана: три самых вероятных места с вероятностями, время анализа и число использованных ракурсов.
- Координаты лучшего варианта автоматически копируются в буфер обмена в виде `55.751244, 37.618423`: их можно сразу вставить в Google Maps или Яндекс Карты.
- Анализ нескольких ракурсов одного кадра (центр, края, весь кадр, приближенные фрагменты) в пределах заданного времени.
- Выбор места по скоплению точек, а не по одной самой вероятной точке: случайные выбросы реже попадают в ответ.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| F6 | Сделать скриншот и определить место |
| F7 | Скрыть оверлей |
| Esc | Выйти из программы |

## Установка и запуск из исходников

Нужен Python 3.10+ и Windows.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python geo_app.py
```

Запускайте от имени администратора, иначе библиотека `keyboard` может не перехватывать F6 вне окна программы.

При первом запуске:
- скачиваются веса модели с Hugging Face (несколько сотен МБ, нужен интернет);
- один раз считаются признаки галереи из 100 000 точек (до минуты на процессоре). Результат сохраняется в файл `geoclip_loc_feats.pt` рядом со скриптом, дальше запуск быстрый.

Если игра запущена в «настоящем» полноэкранном режиме, оверлей может быть не виден. Переключите игру в оконный режим без рамки (borderless).

## Сборка .exe

```bat
build3.bat
```

Скрипт ставит PyInstaller и собирает программу в папку `dist\GeoOverlay`. Готовый файл: `dist\GeoOverlay\GeoOverlay.exe`. Переносить нужно всю папку целиком, а не один `.exe` (размер порядка 1–2 ГБ из-за PyTorch). Программа сама запрашивает права администратора.

## Настройки

В начале `geo_app.py`:

| Параметр | Значение по умолчанию | Что делает |
|----------|----------------------|------------|
| `TOP_K` | 3 | Сколько вариантов показывать |
| `TIME_BUDGET` | 2.5 | Максимальное время «раздумий» в секундах: чем больше, тем больше ракурсов |
| `CLUSTER_KM` | 100 | Радиус, в котором точки считаются одним местом |

## Ускорение на видеокарте NVIDIA

По умолчанию ставится версия PyTorch для процессора. Для видеокарты NVIDIA:

```bash
pip install torch torchvision --force-reinstall --index-url https://download.pytorch.org/whl/cu126
```

Скрипт сам заметит CUDA и переключится на видеокарту.

## Как это работает

1. По F6 делается скриншот основного монитора (в памяти, без записи на диск).
2. Из кадра нарезаются несколько ракурсов, пока не истечёт `TIME_BUDGET`.
3. Каждый ракурс кодируется моделью CLIP и сопоставляется с признаками 100 000 заранее подготовленных точек.
4. Вероятности по ракурсам усредняются, а затем суммируются по близким точкам. Выбирается самое вероятное скопление.
5. Результат показывается в оверлее и копируется в буфер обмена.

## Ограничения

- Модель обучена на фотографиях из интернета, а не на панорамах Street View. На пустых дорогах и однотипных пейзажах она часто ошибается на сотни километров.
- Точность хорошая для страны и региона, а не для конкретной точки.
- Только Windows (используются `keyboard` и `clip`).
